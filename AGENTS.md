# Project Instructions

This file contains persistent instructions and rules for the AI coding agent working on this project.

## Business Rules
- **Consultation Charges:** A consultation fee of 20% of the booking value is applicable for all appointments and expert guidance sessions. This should be clearly stated on all relevant pages (Home, About, Property Details, Book Appointment).

## Content Guidelines
- Always use professional and elite real estate terminology.
- Maintain the "Premium" and "Elite" branding of FPS Motion.

## Technical Details
- **Firebase:** Integrated for Auth and Firestore database.
- **Collections:**
  - `users`: Stores user profile data.
  - `bookings`: Stores appointment details linked to users.
- **Auth:** Supports Email/Password and Google Login.
